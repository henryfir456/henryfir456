## 🧩 Engineering Philosophy

I prefer building systems that are:

- **Observable** — failures should explain themselves
- **Deterministic** — automation should behave predictably
- **Testable** — behavior should be protected by tests
- **Incremental** — small verified changes beat large rewrites
- **Practical** — technology should reduce real friction

I’m especially interested in how AI agents can become part of a disciplined engineering workflow rather than simply generating code.
